What changes

The output is a map, not a deck.

The diagnostic is useful only if it changes the next week of work. The format stays plain: interviews, artifact review, workflow sketching, and a ranked build list.

01

Workflow inventory

Where the same context is re-created, copied, reconciled, explained, or manually checked.

02

Automation judgment

Which tasks are ready for agents, which need better data, and which should stay human.

03

First useful build

One scoped implementation candidate with owner, data path, failure mode, and expected payoff.

Most AI projects fail before the model is chosen. The expensive mistake is automating a workflow nobody has actually described.
Best fitFounder-led teams, operators, analysts, and service businesses with visible manual coordination.
Not a fitOpen-ended AI strategy, brand theater, or a request to replace people before the work is understood.
CadenceTwo calls, artifact review, written map, implementation recommendation, and optional build sprint.
