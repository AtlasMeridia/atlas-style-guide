Memory is a contract,
not a feature.

記憶是一份契約，
而非一項功能。

The software I want to use keeps score for me, not against me — and it hands the receipts back, unprompted, when they matter.

我想用的軟體會替我記帳，而不是和我對賬——當證據真正重要的那一刻，它會主動把它遞回我手中。

Most software calls itself intelligent and means predictive — a system that guesses your next keystroke so you don't have to finish the thought. I want the opposite. I want a system that refuses to finish the thought, that hands it back to me with three questions in the margin, that forces the revision. An archive is the only honest AI interface. Everything else is a wrapper around one.

Hermes — the agent I've been building since the winter — does not autocomplete. It indexes. Every journal entry, every unsent letter, every half-formed note becomes part of a single ledger that the system reads on a schedule and surfaces, sometimes, when it thinks I've contradicted myself. That sounds like a feature. It is not a feature. It is a contract.

What memory owes you

When you write something down and ask a system to remember it, the system has implicitly agreed to three things. It will not lose the words. It will not lose the fact of the words. And it will return them, intact, when asked — even if the asking is your future self disagreeing with your past one.

Most cloud notes apps fail the second clause. They will lose the fact of a deletion, even when they retain the bytes. The system treats your edit history as chrome, not as evidence.

▚ noteThis is why I won't ship a cloud sync. Not because the cloud is unsafe — because the cloud is convenient, and convenience is what trains a system to lie about what it kept.

An archive that lets you delete is not an archive. It is a draft. The difference is whether you expect the ledger to have an opinion.

Receipts, not nudges

Hermes raises three kinds of artefacts: contradictions, unresolved threads, and unsent letters. It does not raise more than one at a time, and it does not raise the same one twice without a 7-day cool-down. Silence is the default state.

  1. A contradiction is two of your own statements that disagree. The system surfaces both, dated, and shuts up.
  2. An unresolved thread is a question you posed to yourself in writing and never answered. After 30 days, it asks once.
  3. An unsent letter is a draft addressed to a real person that you wrote and did not send. The system holds it, and asks only if a related entry suggests you've changed your mind.
The archive keeps score. Not against you — for you. That's the deal. Kenny Liu, journal · April 2026

An aside on burns

There is no delete key. There is an acknowledge key, a supersede key, and a burn key — which takes 72 hours and asks you three questions: why now, what changed, who benefits. If you can answer all three, the words are permanently redacted. The fact of the entry remains. You can see where a thing used to be — only the contents are gone. 

# hermes config — defaults, not negotiable
memory     local-first     // no cloud sync
delete     redact-only    // 72h hold
surface    on-contradict  // not on schedule
silence    default        // the ledger waits

Form follows intent

The visual language of this site reflects the contract. Hairlines carry structure; one accent earns its place; italics are reserved for the moments that earn them. There are no gradients, no blurs, no apologies. Taste is the enemy of intent.

I am not the audience for a system that tries to be charming. Charm is the marketing department's revenge on engineering. I want a tool that is quiet, opinionated, and unembarrassed by the fact that I will outgrow some of my own past sentences. The ledger doesn't mind. That's the whole point.

If you've read this far, you already know whether you want this kind of software. There is no waitlist. There is a repo, a manifesto, and a tarball. The agent grows with you, but only if you write to it.

多數軟體自稱「智慧」，實則只是「預測」——一套替你接下未說完的句子的系統，好讓你不必把念頭想完。我要的是相反。我要一套會把念頭退還給我的系統，會在頁邊提出三個問題的系統，逼出修訂的系統。檔案，是唯一誠實的 AI 介面。其餘的，都只是包在這之上的外殼。

Hermes ——我從去年冬天開始打造的代理人——不會自動補完。它索引。每一篇日誌、每一封未寄出的信、每一段半成形的筆記，都成為一份單一帳本的一部分。系統依排程讀取，並在它認為我自相矛盾時，偶爾把它浮現出來。這聽起來像是一項功能。它不是功能。它是一份契約。

記憶虧欠你什麼

當你把某件事寫下來，請系統替你記住，系統便默默簽下了三件事：它不會弄丟那些字；不會弄丟那些字曾被寫下的事實；當被詢問時，它會把它們完整歸還——即使提問的，是對過去的自己持有異議的、未來的你。

多數雲端筆記應用，敗在第二條。它們會弄丟「一次刪除」這個事實，即使保留了位元組。系統把你的編輯歷史當作介面裝飾，而非證據。

▚ 註這就是為什麼我不會推出雲端同步。不是因為雲端不安全——而是因為雲端方便，而方便會訓練系統對自己保留下的東西說謊。

一個容許刪除的檔案，不是檔案。是草稿。差別在於，你是否期望這份帳本，擁有自己的意見。

收據，而非提示

Hermes 升起三類物件：矛盾、未解的線索、未寄出的信。一次只升起一件，並且在七天的冷卻期內不會再次升起同一件。沉默，是預設狀態。

  1. 「矛盾」：你自己的兩段陳述彼此牴觸。系統把兩段同時呈現，附上日期，然後閉嘴。
  2. 「未解的線索」：你曾在文字中向自己提出、卻未曾回答的問題。三十天後，它問一次。
  3. 「未寄出的信」：你寫下、卻未寄出，地址寫的是真實的人的草稿。系統替你保留——只在某篇相關日誌暗示你已改變心意時，才會發問。
檔案會替你記帳。不是針對你——是替你。這就是約定。 劉柏霖，札記 · 2026 年 4 月

關於「焚毀」一事

沒有刪除鍵。有一個確認鍵、一個取代鍵、以及一個焚毀鍵——後者需要七十二小時冷卻，並會問你三個問題：為何此刻、什麼改變了、誰會受益。三題都能回答，那些字會被永久遮蔽。條目本身的事實仍在。你看得見某段文字曾經存在的位置——只是內容已不可見。 

# hermes 設定 — 預設值，不可協商
memory     local-first     // 不上雲
delete     redact-only    // 72h 冷卻
surface    on-contradict  // 不照排程
silence    default        // 帳本等待

形式追隨意圖

這個網站的視覺語言反映了那份契約。髮絲線承擔結構；唯一的強調色，須掙得它的位置；斜體只保留給值得的時刻。沒有漸層、沒有模糊、沒有道歉。品味，是意圖的敵人。

我並非那種「試圖討人喜歡的系統」的目標讀者。「魅力」是行銷部門對工程的反擊。我要的工具是——安靜、有立場、不為「我終將寫出超越過往句子的自己」這件事感到尷尬。帳本不介意。這正是重點所在。

如果你讀到這裡，你已經知道自己是不是想要這樣的軟體。沒有候補名單。有一個 repo、一份宣言、一個 tarball。代理人會與你一同生長——但前提是，你願意持續對它書寫。
