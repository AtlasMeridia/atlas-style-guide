# v1 archive

This folder contains the pre-Minerali ATLAS Meridia style-guide app that used
the older navy / cream / amber system and Next.js token editor.

It was moved here on 2026-06-30 when Minerali v6 became the active root design
system for `kennyliu.io` and internal ATLAS / AtlasCortex projects. Keep it for
reference, migration, or rollback. Do not start new design work from this folder
unless explicitly asked.
