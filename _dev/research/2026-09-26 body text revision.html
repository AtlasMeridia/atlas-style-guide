Why the body text reads muddy

Three settings compound: reading copy in the secondary color, a weight below regular, and an optical size pinned above the type size. Flip the theme with the toggle in the corner; every specimen is live CSS.

01 · Color

Reading copy is set in the secondary color

.prose, .body-text, and .lead use --text-secondary. It passes AA, but it sits at a middling value in the same warm hue as the ground, and that is what reads as mud. The blog body escapes only because blog-post.css overrides it; its lead paragraph doesn't.

02 · Weight

The weight splits by theme

Light text on a dark ground blooms, so on graphite a thinner stroke reads crisper. Now that the body is in the primary color, graphite can go lighter than today's 340. Cream goes the other way: dark text on a light ground has no reason to go below 400. Try the options in each theme.

03 · Optical size

The optical size is pinned above the type size

.prose forces 'opsz' 28 on 20px text, and .lead forces 40 on 24px. Higher optical sizes are cut for display: finer hairlines, tighter fit. Letting the browser match opsz to the real size restores the stroke contrast Literata was drawn with. The strip below each specimen is the same 20px text magnified 3×.

04 · The diff

What changes in colors_and_type.css

Adopted 2026-09-26 with graphite at 300. All edits are in the shared stylesheet. Consuming projects pick them up on their next copy.

/* graphite */
  --body-weight:   340;
  --body-weight:   300;   /* lighter on dark — see 02 */

/* cream */
  --body-weight:   380;
  --body-weight:   400;

.prose, .body-text {
  font-variation-settings: 'opsz' 28;
  font-optical-sizing: auto;
  color: var(--text-secondary);
  color: var(--text-primary);
}

.lead {
  font-variation-settings: 'opsz' 40;
  font-optical-sizing: auto;
  font-weight: 400;
  font-weight: var(--body-weight);
  color: var(--text-secondary);
  color: var(--text-primary);
}
  • Secondary stays for decks, captions, marginalia, and supporting copy, where a step down in value is the point.
  • Grayscale smoothing stays. Switching it off rendered graphite noticeably heavier in the comparison.
